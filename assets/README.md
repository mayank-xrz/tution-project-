# Image assets

Drop the two tutor photos here using these exact filenames:

| File | Tutor |
|------|-------|
| `tutor-sangita.jpg` | Sangita Biswas |
| `tutor-supriya.jpg` | Supriya Pandey |

The page references them directly — no code changes are needed once the files
are in place. Until then, each card shows a styled initials placeholder
(the `<img>` removes itself on load error).

## Requirements
- **Use licensed / owned photos.** Do not use watermarked stock-photo
  previews (e.g. Shutterstock or Dreamstime comp images) — the watermark
  is visible and the comp licence does not permit website use.
- Roughly **4:3** or portrait orientation works best; the image is
  cropped with `object-fit: cover` (anchored to the top so faces stay in
  frame).
- Suggested size: ~800×600 px or larger, optimised JPG/WebP.
